SOLO LEVELING - Workout System

Phone pe install karne ke steps:
1. Is zip ko extract karo.
2. Folder ko https://app.netlify.com/drop pe drag & drop karo (free, account ki zarurat nahi ho sakti) ya GitHub Pages pe upload karo.
3. Jo https link mile use phone ke Chrome (Android) ya Safari (iPhone) me kholo.
4. Menu me "Add to Home screen" / "Install app" dabao. Logo ke saath app home screen pe aa jayega.

Note: index.html ko seedha file se kholne par install option nahi aata, hosting zaruri hai.
Phone silent mode me ho to sound effect nahi aayega.
